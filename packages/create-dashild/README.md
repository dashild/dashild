# create-dashild

Crea un proyecto Next.js con Dashild preconfigurado.

**No publicado en la alpha.** El paquete todavía es un stub y sale con código 1.
Usa `@dashild/cli` manualmente:

```bash
pnpm add @dashild/core@alpha @dashild/admin@alpha @dashild/prisma@alpha
pnpm add -D @dashild/cli@alpha
pnpm dashild init
```

Se publicará cuando reutilice el mismo core que `dashild init`.
